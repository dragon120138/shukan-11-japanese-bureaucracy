# 【书刊11】 官厅日本官僚制的组织解剖

> 学术·组织

## 关于本书

解剖日本官僚制这个创造战后奇迹、又在三十年停滞中被问责的组织机器。组织学路径：不满足于印象批评，拆开机器看零件——省厅权限争夺如何塑造政策、审议会如何制度化利益协商、精英晋升设计决定谁在何时说话、下凡旋转门的运作。材料来自组织研究文献与政策史，判断均标注出处。

## 篇目

- 第5章素材库：GHQ 改造与战后行政国家的诞生（1945-1952）
- 第6章 素材库：高度成长的官厅，通产省神话与护送船团（1955-1973）
- 第7章 素材库：天下り与族议员，官僚的政治经济学
- 第8-9章 素材库：失落的十年与2001再编（1991-2014）
- 第10章 令和的官厅：デジタル庁、政治主导与官僚制的未来（2015–2026）
